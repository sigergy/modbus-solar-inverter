# 0008 — AGPL-3.0

## Contexto

El proyecto empezó con PolyForm Noncommercial 1.0.0 (sin uso comercial previsto). Se cambia a una licencia copyleft aprobada por OSI.

## Decisión

`LICENSE` es el texto oficial de GNU Affero General Public License v3.0 (`LICENSE:1-2`).

## Consecuencias

- AGPL-3.0 está aprobada por OSI: `hacs/action` ya no necesita ignorar el check `license`.
- Las versiones publicadas antes de este cambio conservan la licencia con la que se publicaron (PolyForm Noncommercial 1.0.0).
